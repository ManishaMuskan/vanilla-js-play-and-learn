Event Bubbling and Event Capturing

Trickling Down and Bubbling up - this is phrase to remember the concept

Event Propagation cycle

when an element is attached to an event it goes through event propagation cycle, first it goes through event trickling phase where the event occurs from the top most parent till the event of target element is reached.

After that, it goes through event bubbling phase where it bubbles up the event from target element till it reaches to the top most parent in DOM tree hierarchy

this behavior can be controlled by using third argument while attaching an event listener to the element, 'useCaptureFlag' - when the value is falsy or value is not provided, event bubbling phase is enabled. and when the value is true, event capturing mode is enabled. And based on this mode, event-propagation cycle is completed when a target element trigger an event

Event Delegation

it is a feature by using which we can attach an event-listener to all the child items by just attaching an event-listener to the parent element. As by-default events get bubbled up, this gives us the flexibility to attach one only event-listener to the parent element to control the behavior of child elements
